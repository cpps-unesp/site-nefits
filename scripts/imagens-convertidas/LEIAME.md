Versões JPEG das imagens SVG usadas no conteúdo antigo (fotos da equipe,
imagens da página Sobre e uma capa de notícia). O EmDash não aceita SVG na
biblioteca de mídia, então `npm run importar-conteudo` envia estas versões no
lugar dos SVGs de `public/`. Cada arquivo tem o mesmo caminho do SVG original.
